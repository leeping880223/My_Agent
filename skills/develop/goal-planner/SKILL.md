# goal-planner：長期目標規劃

## 目的

把使用者的目標轉換成可執行的長期計畫表，並確保計畫建立在使用者實際擁有的資源與技能上，而不是空想。

## 執行步驟

1. **理解目標**
   - 使用者提出目標後，先確認：目標的具體定義、成功標準、期限（若有）。

2. **盤點現況**
   - 讀取 `data/profile/skills.md`，掌握使用者已具備的技能與程度。
   - 詢問使用者：
     - 目前有哪些可用資源？（時間、設備、資料、經費、人脈、既有程式碼等）
     - 除了 skills.md 記載的以外，還有沒有相關經驗或技能？
   - 若問出 skills.md 沒有的技能，順手更新 `data/profile/skills.md`。

3. **產出長期計畫表**
   - 把目標拆解成階段性任務，每個任務包含：任務名稱、預估時程、前置依賴、產出物。
   - 排序原則：先做能驗證可行性的（降風險），再做累積性的工作。

4. **寫入 `data/goals.md`**
   - 格式固定分為兩區：
     ```markdown
     # 長期計畫表

     ## ✅ 已完成
     - [x] <任務>（完成日期：YYYY-MM-DD）— <一句話成果>

     ## 🚀 即將要做
     - [ ] <任務>（預估：<時程>；依賴：<前置任務或無>）— <產出物>
     ```
   - 若 goals.md 已有內容，將新計畫合併進去，不要覆蓋既有的已完成紀錄。

5. **收尾**
   - 向使用者展示計畫表並確認。
   - 提醒：日後計畫需要調整時使用 `plan-adjuster`，任務完成後把項目從「即將要做」移到「已完成」。
