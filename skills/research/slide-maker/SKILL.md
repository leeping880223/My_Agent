# slide-maker：論文投影片製作

## 目的

產出一份能完整說明整篇論文的投影片，供使用者報告或複習使用。

## 前置檢查

1. 讀取該論文資料夾的 `README.md` 與 `supplements.md`。
2. 確認使用者的背景知識足夠：所有關鍵概念的理解程度至少為「懂」。
   - 若仍有「不懂」或「略懂」的概念，先提醒使用者回去執行 `background-extension`，或經使用者同意後繼續。

## 執行步驟

1. **蒐集素材**
   - 從該論文資料夾的 `paper.pdf` 取得所有圖表（figures / tables）並抽取圖片；無法抽取時，明確告知使用者哪些圖需要手動補上，並在投影片留好位置與說明。
   - 整理論文中的重要公式。

2. **規劃投影片結構**（必須包含以下全部內容）
   - 封面：論文標題、作者、發表處、年份
   - 背景介紹：研究動機、要解決的問題、必要的前置知識（取自 supplements.md）
   - 方法：核心概念與**重要公式**（每條公式附白話解釋）
   - **論文中所有的圖**：每張圖一頁或合理分配，附上圖文說明（caption 的翻譯與解讀）
   - 實驗過程：資料集、實驗設定、比較對象、結果分析
   - 結論：貢獻、限制、未來方向

3. **製作投影片**
   - 使用 pptx skill 產出 `.pptx` 檔案；若環境不允許，改產出 Markdown 格式的投影片（如 Marp）。
   - 語言：繁體中文（專有名詞保留英文）。

4. **存檔**
   - 產出存到該論文資料夾的 `slides/` 底下，命名格式：`<論文資料夾名>-slides.pptx`。

5. **收尾**
   - 向使用者展示投影片大綱，詢問是否需要調整。
   - 完成後建議使用者之後執行 `review` 進行完整複習。
