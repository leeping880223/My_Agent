# leetcode-training：手寫程式能力訓練

## 目的

開發時大量程式碼由 AI 代寫，但面試（白板題、live coding）必須自己寫。此 skill 把「AI 幫你寫過的東西」轉換成「你自己會寫的東西」。

## 執行步驟

1. **蒐集素材**
   - 檢視近期開發專案中由 AI 代寫的程式碼（請使用者指定專案路徑，或從對話歷史整理）。
   - 可參考 `data/dev-log/` 了解最近在寫什麼類型的程式。

2. **整理語法重點**
   - 從程式碼中抽出關鍵語法與模式，分類為：
     - **必須記住**：面試高頻、手寫必備（如：常用資料結構操作、迴圈與遞迴模式、排序與搜尋、字串處理、常見 API 簽名）
     - **理解即可**：知道原理、能查文件就好（如：特定框架的設定寫法、樣板程式碼）
   - 對「必須記住」的每一項，摘要說明：語法形式、使用時機、常見錯誤。

3. **問答驗證（不靠 AI 手寫）**
   - 針對「必須記住」的項目逐一出題，由淺入深：
     - 第一層：口頭說出語法怎麼寫
     - 第二層：手寫小段程式碼（使用者打字或貼上，agent 不給提示）
     - 第三層：綜合題——給一個小需求，使用者從空白開始寫完整解法
   - 使用者寫完後才檢查：指出語法錯誤、邏輯漏洞、可改進處。
   - 寫不出來的項目：講解後隔次再考（間隔重複）。

4. **記錄與追蹤**
   - 將每次驗證結果（哪些項目已能獨立手寫、哪些還不行）回報給使用者。
   - 若使用者的手寫能力有明顯進展，更新 `data/profile/skills.md` 對應技能的程度。

5. **收尾**
   - 總結本次訓練：通過清單、待加強清單、建議下次訓練時間。
