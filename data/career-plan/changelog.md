# 職涯目標變更紀錄

由 job-matching 維護，記錄每次職涯目標的變更與原因。

| 日期 | 變更內容 | 原因 |
|---|---|---|
| 2026-08-20 | **首次設定職涯方向**：具身智能／機器人 AI 演算法工程師（大腦層）。目標職缺分四級：T1 達明／台達／Solomon、T2 機器人視覺、T3 IPC 的 Edge AI、T4 新創觀察名單。同時確立角色定位——創新在大腦層、小腦要能接得起來但不做創新、不碰硬體選型。 | 2026 自動化展兩天實地觀察：技術棧與碩論高度重疊的公司集中在 T1；IPC 廠商多為硬體軟體整包銷售，規格由採購決定，與使用者的實際分工不符。定位取自工研院實習的實際工作內容。 |
| 2026-08-20 | **補強策略定為「論文即補強」**：T1 的 12 項需求有 9 項會在論文階段一～五自然補上，僅 ROS2、C++、手寫程式能力需額外安排。 | 論文方向（VLA ＋ 影像主線）與 T1 職缺需求幾乎一致，不需要另開學習計畫。 |
| 2026-08-21 | **加入三條硬性條件**：① 地點限竹北／大新竹 ② **職能必須是軟體／演算法／研究性質** ③ 出差駐廠比重列入評估。 | 使用者告知。第 ② 條的來源是從台積電 **EUV 模組副工程師**離開去唸碩士的動機——**是對軟體與研究有興趣（趨向），不是為了避開輪班（迴避）**。因此篩選器要設在「職能」而非「班別」：日班但非軟體的職缺（應用工程、業務工程、廠務）一樣排除；而**半導體產業本身沒有被排除**。第 ① 條直接推翻原 T1 的排序（達明在桃園、台達在桃園／台北、Solomon 在新北）。 |
| 2026-08-21 | **職涯方向改為兩階段**：第一階段＝半導體缺陷檢測／量測設備商的影像演算法（約 5–7 年，高薪）；第二階段＝工研院那類機器人與自動化環境。貫穿兩階段的方法主線是**合成資料生成**。 | 財務目標有明確終點（竹北買房頭期款）＋生活支出低 → 適合「先衝一段再轉軌」。量級估算顯示高薪路線與法人路線的買房時間差約 4–6 年。順序上先賺後轉比反過來容易：法人環境不挑年齡，高薪高強度的地方偏好年輕。 |
| 2026-08-21 | **job-targets 全面重排**：新 T1＝半導體缺陷檢測／量測設備商影像演算法、T2＝晶圓廠智慧製造／AI、T3＝電子製造／面板 AOI、T4（第二階段）＝工研院與機器人自動化；原 T1（達明／台達／Solomon）因地點不符降級。**刻意排除**輪班職能、IC 韌體與 DV（完全轉行、碩論歸零）、設備 tech 供應商。 | 依新的硬性條件與兩階段方向重算。核心判準是「**在 EUV 機台前站過 ＋ 會做缺陷檢測演算法**」這個罕見組合，優先押在吃得到這張牌的職缺上。 |
| 2026-08-21 | **記入策略的三個防護**：① 買房時刻意留餘裕（保留未來減薪 40% 的空間）② 高薪期做可攜的東西（設備商演算法 > 晶圓廠內部系統）③ 不要斷掉工研院那條線。 | 「先賺後轉」最大的失敗模式是**房貸把人鎖在高薪工作上**，講的人多、做到的人少。三個防護是讓這個策略真的能執行的前提，缺一個就會壞掉。 |
| 2026-08-21 | **興趣主線更正為「自動化與提升工作效率」**，影像辨識降為工具而非目的（入學後才接觸）。連帶新增 **T2b：晶圓廠／設備的自動化與控制軟體**（含新代科技），並在 job-targets 加註「不要只沿著影像找職缺」。 | 使用者更正：當初想唸的是「控制組自動化相關的研究」，動機是「很樂愛提升工作效率」。原本整份 job-targets 全部沿著影像排序，會整片漏掉控制／自動化／系統整合——而那正是最初想做的方向。 |
| 2026-08-21 | **推翻「研究是已付出代價的沉沒成本」這個論證。** 唸碩士的實際原因是**升等路徑計算**：職稱為模組副工程師，兩年內升不上設備工程師，不如出來唸書；且唸完想回去就直接是設備工程師。 | 使用者更正。影響有二：① 機會成本比原先估的低（留下來兩年也升不上去），故「第二階段權重要拉高」的理由不成立；② **存在回台積電當設備工程師的保底退路**，但該退路與硬性條件②衝突，只能當安全網不能當計畫。 |
| 2026-08-21 | **地點條件的來源查明**：竹北／大新竹**不是本人偏好，而是女朋友在新竹上班**；本人現住台北、家也在台北。因此把達明／台達／Solomon 從「降級刪除」改為**「地點條件變動時的候選」保留**。 | 使用者告知。此條件比一般的居住偏好更容易變動（女方換工作、或兩人住在中間），故被它篩掉的目標不應刪除。⬜ 待確認彈性：是「必須同住新竹」還是「離得夠近就好」——後者的話桃園回到選項內。 |
| 2026-08-21 | **依碩一成績單修正兩個排除判斷**：IC 韌體與 DV 都**不是「完全轉行」**（修過 FPGA 電路設計與合成 93、數位積體電路設計 90、C++ 自學與嵌入式實作），排除理由改為「碩論用不上、與自動化主線繞遠路」。同時 **T2b 的底氣上修**（控制系統 83、智慧型控制 90 是修過課的）。 | 取得 114 學年度成績單。先前的排除判斷建立在對背景的推測上，與實際修課記錄不符。 |
| 2026-08-21 | **新增可談的差異化第 1 項：大學成績中下（GPA 2.609、系排 66%）→ 碩士 92／89.2 的翻轉。** | 碩一兩學期成績與大學落差極大，且動機轉折有 2024-11 自傳的書面出處，構成完整敘事。這是面試被問大學成績時唯一有效的回答方式。 |
| 2026-08-21 | **地點從「硬性條件」降為「權衡條件」。** 硬性條件只剩一條（職能必須是軟體／演算法／研究性質）；地點與駐廠出差改列成本欄位，逐案用**薪水／通勤難易度／工作內容／未來發展**四因子評分。連帶把達明／台達／Solomon 從候選區恢復為 **T1b 主目標層級**，並註明 **T1a 與 T1b 何者為主，與論文主體綁定**。 | 使用者表示這條沒有固定答案，取決於上述四個因子的組合。既然如此它就不是篩選器——用它先刪目標會刪錯。附帶推論：**四個因子全部來自正式 JD 與實地通勤查證，而目前一份都沒有**，故「取得 3 份 JD ＋ 查通勤時間」升級為解開地點問題的唯一途徑。 |
| 2026-08-21 | **通勤條件部分定案，但地點問題整體延後。** 已知：若住新竹，**通勤到桃園不接受**（太累、超過半小時、且無自用車）→ T1b 只有在「最終不住新竹」時成立。但「要不要住新竹」取決於女方工作（浮動中），**現在不投入力氣查通勤與地點**。 | 使用者告知。關鍵推論：**地點這條變數在 2026-11 決策閘門前不會收斂，因此不能拿來當論文主體的判準**——論文決定要回到「教授擔保」與「資料在手」這兩條會如期有答案的軸上。 |
