## 概念 1：什麼叫「空間被弄彎」——代價地圖與測地線

論文第一段就說「障礙物在空間裡變成洞，直線不再是合理的最短距離定義，測地線必須自然地繞過它們」。這句話是全篇的地基，但論文假設你已經懂。這一節從高中物理搭上去。

### 第 1 階：救生員問題（高中物理）

救生員站在沙灘上，溺水者在斜前方的海裡。他在沙灘上能跑 5 m/s，在水裡只能游 1 m/s。

**最快的路線不是直線。** 最快的走法是：先在沙灘上多跑一段、斜著切到離溺水者比較近的下水點，再游比較短的距離。路線會在水邊**轉折**。

為什麼？因為「距離短」不等於「時間短」。真正決定路線的是——**每個地方移動的代價不一樣**。

（這就是光的折射，也是費馬原理：光走的是最省時間的路，不是最短的路。）

### 第 2 階：把「代價」畫成一張地圖

把上面的想法寫下來：畫一張地圖，每個位置標上「在這裡移動 1 公尺要付出多少代價」。

| 區域 | 代價（秒／公尺） |
|---|---|
| 沙灘 | 0.2 |
| 海水 | 1.0 |

有了這張表，任何一條路線的總代價都能算出來（把沿路每一小段的長度乘上當地代價，加起來）。**最快路線＝總代價最小的那條路線。**

**注意代價和速度的方向相反**：代價是「走 1 公尺要**付出**多少時間」，速度是「1 秒能**得到**多少公尺」，兩者互為倒數。

> **跑得快 ＝ 代價低（便宜）；走得慢 ＝ 代價高（貴）。**

沙灘跑 5 m/s → 代價 0.2 秒/公尺（便宜）；海水游 1 m/s → 代價 1.0 秒/公尺（貴五倍）。所以最快路線會**盡量待在便宜的地方**。

**這張代價地圖，就是「度量」。**

### 第 3 階：代價還可以分方向（接回你已經懂的「發言權」）

上面的代價只跟「在哪裡」有關。但代價還可以跟「**往哪個方向走**」有關——想像沙灘上有一道道與海岸平行的深溝：**沿著**溝走很輕鬆，**橫越**溝走很費力。同一個位置，不同方向，代價不同。

你在 2018 那篇學過矩陣 `A` 是「發言權表格」。現在請加上第二種讀法，兩種是同一件事：

> **發言權高的方向 ＝ 移動代價高的方向。**

為什麼等價？發言權高的意思是「這個方向被別人拉走，我會很不爽」；而「不爽」就是代價。反過來，發言權 0 的方向＝「你要怎麼動都行」＝**在那個方向移動是免費的**。

用你熟的避障度量 `diag(9, 0)` 算算看：

| 方向 | 發言權 | 移動代價 |
|---|---|---|
| 朝向障礙物 | 9 | 很貴（走一步付 9） |
| 側向（平行障礙物表面） | 0 | **免費** |

於是「最省的走法」自然變成：**盡量不要朝障礙物移動，側向要怎麼滑都可以**。你在 2018 概念 1 第 5 階算過的那個數字例子（合成後貼著障礙物滑過去），從代價的角度看就是這個結論。

### 第 4 階：代價地圖不均勻 → 最省的路徑自己就是彎的

現在給這件事一個正式名字。

> **測地線（geodesic）＝ 在給定的代價地圖下，總代價最小的那條路徑。**

- 代價**處處相同**（均勻平坦）→ 測地線就是我們熟悉的直線。
- 代價**不均勻** → 測地線是彎的。救生員那條折線，就是一條測地線。

所以「空間被弄彎了」這句話，意思**不是**空間真的凹下去或凸起來，而是：

> **代價地圖不均勻，於是「最省的走法」本身就是彎的。**

「直線」的真正定義從來不是「看起來直」，而是「**最省的走法**」。代價一變，什麼叫直，就跟著變。

### 第 5 階：機器人版本——代價地圖是「設計」出來的，不是天生的

前面救生員的代價地圖是物理給定的（沙灘就是比海水好跑）。但在機器人身上，**代價地圖是工程師自己畫的**——這一點很關鍵，決定了整套設計哲學。

流程是反過來的：

1. 先決定**要什麼行為**：「越靠近柱子，就越不該再往它移動」
2. 再把這個願望**寫成代價地圖**：離柱子越近，朝向柱子的方向就越貴

論文 3.6 節就是這樣寫的：權重函數 `w(x)` 被設計成「距離 x 變小時 w 變大」，2D 實驗裡用的是 `w(x) = 1/x⁴`（距離的四次方分之一，靠近時暴增）。

所以「為什麼越靠近泥越深？」的答案是：**因為我們就是這樣設計的。** 這樣一來，避障不必再額外掛一個推力——它變成「走最便宜的路」的自然結果。

有了這張自己畫的地圖，障礙物周圍就是——**越靠近柱子代價越高，像一圈越陷越深的泥沼**。

於是：
- 正對著柱子走 → 一路踩進越來越深的泥沼 → 極貴
- 沿著柱子邊緣切過去 → 一直待在同樣深度的泥上 → 便宜得多

**最省的路徑（測地線）自己就會繞開柱子。** 沒有人推它、沒有人拉它——只是別的走法比較貴。

這就是論文引言那句話的完整意思，也是 RMPflow 整套框架的世界觀：**避障不必靠「推開」，把代價地圖設對，繞開是自然結果。**

### 對應到 G1 專案

你 `g1_rmpflow_common.yaml` 裡每個 `body_cylinders` 都在畫一小塊高代價區。你調的那些參數，本質上是在編輯這張代價地圖：哪裡貴、貴多少、貴的是哪個方向。

### 檢驗自己是否懂了

1. 救生員為什麼不走直線？用「代價」這個詞回答。
2. 「發言權 0 的方向」用代價的語言講是什麼意思？
3. 「空間被弄彎」是說空間真的凹凸不平嗎？如果不是，是什麼？

## 概念 2：曲率項 Ξ_G 和 ξ_G

> 📖 **先看：論文 Fig. 3（第 13 頁）的五格圖，特別是 (a) 和 (b) 的對比。** (a) 沒有曲率項，粒子直直穿過去；(b) 只加了曲率項（沒有任何斥力），粒子就自己繞著障礙物轉。看過這兩格，下面的文字才會有畫面。

這是本篇最大的缺口，也是 Fig. 2、Fig. 3 兩組實驗的主角。先講清楚一句話：

> **曲率項不是力。它是「代價地圖在你腳下不均勻」造成的偏折。**

### 第 1 階：等速轉圈也需要加速度（高中物理）

車子用固定速率 60 km/h 繞圓環。速率從頭到尾沒變，但你會被甩向外側——因為**方向一直在變**。

高中物理課本寫過：**加速度不是只有「變快變慢」，改變方向也是加速度**（向心加速度 = v²/r）。這一階只要記住：

> **方向改變本身就是一種加速度。**

### 第 2 階：方向為什麼會改變？兩種完全不同的來源

| 來源 | 例子 | 感覺 |
|---|---|---|
| (i) **有人施力** | 有人從旁邊推你一把 | 被推 |
| (ii) **你走的路本身是彎的** | 在山路彎道上開車，你想照直開就會衝出路面；順著彎走才省力 | 沒人碰你，路就是那樣 |

**曲率項屬於 (ii)。** 避障斥力和目標吸引力屬於 (i)。

### 第 3 階：代價地圖不均勻，怎麼把你帶偏

回到泥沼。這次的泥沼**越靠近柱子越深**（不是均勻的一片）。

你以固定的速度朝斜前方走。此時你的**左腳踩在較淺的泥、右腳踩在較深的泥**——右腳比較難拔起來，於是你自然而然被帶著往右偏。

**沒有人推你。你的意圖也沒變（還是想往斜前方走）。是兩隻腳踩到的代價不一樣，把你的方向擰過去了。**

這正是曲率項在計算的東西：**代價地圖在我腳下的變化率 × 我的速度**。

### 第 4 階：為什麼一定要乘上速度（而且是速度平方）

三個直覺，一起記：

1. **站著不動就不會被帶偏。** 泥深不均，但你沒在走，當然不會偏。→ 所以曲率項裡一定含速度，速度為零時整項消失。
2. **走得越快，偏得越厲害。** 同樣的泥深差，快步衝過去被扭得更兇。
3. **快一倍，偏四倍。** 因為兩件事同時加倍：單位時間走過的距離加倍（踩到的深度差加倍），而你在那段時間內的動量也加倍。

論文的 `ξ_G` 裡面確實是速度的**二次式**（`ẋᵀ...ẋ` 的形式）。

高中物理的對照：**向心加速度 `v²/r` 也是速度平方**。這不是巧合——它們本來就是同一種東西。論文在 4.1 節明講：當代價地圖只跟位置有關（不含速度）時，`ξ_G` **就是古典力學的 Coriolis 力** `C(x, ẋ)ẋ`。

> 換句話說：**曲率項不是新發明的怪東西，是把 Coriolis 力／離心力推廣到「代價地圖可以任意不均勻」的情況。**

### 第 5 階：和你已經懂的 `J̇ẋ` 的分工

這兩個是同一家族的兩兄弟，都是「**腳下的東西自己在變**」而冒出來的加速度，都正比於速度，古典力學裡都有對應：

| | 誰在變 | 比喻 | 來自 |
|---|---|---|---|
| `J̇ẋ` | **換算表**（Jacobian） | **旋轉木馬**：你站的平台自己在轉 | task map 是非線性的 |
| `Ξ_G`、`ξ_G` | **代價地圖**（度量） | **深淺不均的泥沼**：你踩的地不一樣軟 | 度量不是常數 |

兩者要一起算對，設計的行為才會真的跑出來——這是本篇相對 2018 版最實際的兩個修正。

### 第 6 階：論文式 (3) 逐字拆解

現在可以直接讀論文第 4.1 節的核心方程式了：

```
( G + Ξ_G ) ẍ  +  ξ_G   =   −∇Φ   −   B ẋ
└──────┬─────┘    └─┬─┘      └─┬─┘     └─┬─┘
   有效慣性       被帶偏      坡度      阻尼
```

| 項 | 白話 |
|---|---|
| `G` | 代價地圖本身（度量） |
| `Ξ_G` | 代價地圖會變，對「慣性」造成的修正 |
| `ξ_G` | 代價地圖不均勻，把我帶偏的那一份 |
| `−∇Φ` | **位能的坡度**——避障斥力、目標吸引力全都在這裡 |
| `−Bẋ` | **阻尼**——像在水裡走路，速度越快阻力越大，負責讓系統停得下來 |

**一句話記住整條式子，也順便記住曲率項和斥力的本質差別：**

> **左邊是「地形怎麼影響我」，右邊是「有誰在推我拉我」。曲率項在左邊，斥力和吸引力在右邊。**

（`Φ` 讀作 phi，是位能函數；`∇Φ` 是它的坡度，高中的「重力位能越高處、球越往低處滾」就是這個。負號代表往低處走。）

### 第 7 階：論文 Fig. 3 的四格對照——為什麼說「架構不保證好行為」

論文做了一個乾淨的 2D 實驗：一個粒子朝目標飛，中間一個圓形障礙物。

| 設定 | 結果 |
|---|---|
| (a) 沒曲率項、沒斥力位能 | **直線等速前進，完全不理障礙物** |
| (b) **有曲率項、沒斥力位能** | **自己繞著障礙物轉圈** |
| (c) 沒曲率項、有斥力位能 | 被推開了，但動作僵硬，在障礙附近**震盪** |
| (d) 有曲率項、有斥力位能 | 平順地繞過去 |

**(b) 是最關鍵的一格**：那裡完全沒有任何推力，也沒有任何吸引力，粒子卻自己繞開了——這是曲率項存在的直接證據。

**(b) 到底在發生什麼事，要一次講清楚三件事：**

| | 為什麼 |
|---|---|
| **不會撞到障礙物** | 越往裡代價越高（泥越深），它進不去 |
| **不會被彈開** | 沒有斥力位能，沒有任何東西在推它 |
| **沿著「等深線」繞** | 因為那是最省的走法：一直待在同樣深度的泥上 |

論文的原話是把系統「哄向障礙物的**等值線**（isocontours）」——粒子繞的是**一圈固定深度的線**。

> ⚠️ **千萬別把這裡想成「球掉進碗裡」。** 碗會讓球滑向中心、最後停在碗底或撞上中心的東西；這裡的粒子**永遠不會碰到障礙物**。
>
> 正確的圖像是**一圈越往內越陷的泥環**：粒子每次想往內切，靠內側那一邊就陷得更深、被絆住而轉向，於是它一直沿著環的邊緣繞。**繞的是邊緣，不是滑向中心。**

論文對 (c) 的評語值得抄下來：忽略曲率項時軌跡會震盪，「**in practice, this can result in jittery behavior on manipulators**」（實務上會造成機械臂抖動）。

**所以：用了 RMPflow 這個框架，不保證動作平順。平順是那些幾何項在提供的。** 同一套架構，`J̇ẋ` 少扣一項、曲率項省略掉，跑出來就是完全不同的行為。

### 對應到 G1 專案

- 末端在障礙物附近抖動時，除了「調參數」，還有第二條病因可查：**幾何項有沒有被正確計算**。
- 這也解釋了為什麼避障不能只靠把斥力調大：那是 (c)，越調越僵硬。

### 檢驗自己是否懂了

1. 曲率項是「有人推你」還是「地不好走」？在式 (3) 裡它站在等號哪一邊？
2. 為什麼站著不動時曲率項是零？
3. Fig. 3(b) 裡沒有任何斥力，粒子為什麼會繞著障礙物轉？它最後會撞上障礙物嗎？為什麼？
4. `J̇ẋ` 和曲率項都是「腳下的東西在變」，具體各自是什麼在變？

## 概念 3：Natural gradient（補 knowledge-map 的舊缺口）

> 📖 **本節無圖**。承概念 1 的代價地圖繼續走，不需要翻論文。

這條在 2018 那篇被列為「選讀」，一直標著「不懂」。現在補正好——它和概念 1、2 是同一套幾何，而且本篇 4.1 節末尾直接用它來解釋整條核心方程式。

### 第 1 階：蒙眼下山，但地面軟硬不同（承 2018 概念 3）

蒙著眼下山，只憑腳感往最陡的方向走。但如果某個方向是**鬆軟沙地**（走一步滑半步）、另一個方向是**硬土**（走一步是一步），只看「哪邊最陡」就會吃虧——你朝沙地方向拚命走，實際上沒前進多少。

**聰明的走法：先看地形，再決定步伐。**

這跟概念 1 的代價地圖是同一件事：每個方向「走一步的代價」不一樣。

### 第 2 階：一個小數字例子

假設你在調兩個旋鈕：

| 旋鈕 | 特性 |
|---|---|
| A | 超級敏感，動 0.01 整個系統就大變 |
| B | 很鈍，動 1.0 才有一點反應 |

現在「坡度」（梯度）告訴你：兩個旋鈕都該往正方向轉 1 個單位。

照做的話：旋鈕 A 轉 1 個單位 → 系統直接炸掉。

正確做法是**把步伐除以敏感度**：A 只轉 0.01，B 轉 1.0。寫成矩陣就是把梯度乘上「敏感度表格」的**逆**：

```
一般梯度下降：  步伐 = −∇Φ            （只看坡度）
natural gradient：步伐 = −G⁻¹ ∇Φ       （坡度先除以地形）
```

`G` 就是概念 1 的代價地圖（度量），`G⁻¹` 就是「除以代價」。代價高的方向除得多、步伐小；代價低（免費）的方向除得少、步伐大。這就是 Amari (1998) 的 natural gradient。

### 第 3 階：本篇怎麼用它

論文 4.1 節最後一句話，把式 (3) 整條重新詮釋了一遍（原文說得很簡短，這裡展開）：

> 式 (3) 做的事，就是把**幾何加速度** `a_G` 設成「**負的 natural gradient** `−G⁻¹∇Φ`」，再加上一份阻尼 `−G⁻¹Bẋ`。

翻成白話：

> **RMPflow 的核心方程式，字面上就是「在代價地圖上做 natural gradient 下降」＋「阻尼」＋「曲率修正」。**

三個零件各司其職：
- **natural gradient**：往目標走，而且走法有考慮地形（不是傻傻地照坡度衝）
- **阻尼**：避免衝過頭、負責停下來
- **曲率項**：地形不均勻造成的偏折（概念 2）

### 第 4 階：為什麼這件事重要——座標無關

natural gradient 有一個關鍵好處：**不管你用哪組座標描述問題，走出來的路徑都一樣**。

因為它「搬動策略時，連同量尺（度量）一起搬」——你在 2018 學到的 pullback `JᵀAJ`（策略和度量一起變換）遵守的正是同一條規則。

這就是論文說「同一組子任務 RMP 換一台機器人還能用、幾乎免調參」的理論根據（本篇 4.4 節把它證成定理，那是 A 區概念 6 的內容）。

### 帶走的重點

不需要會算任何公式，記住兩句：

1. **natural gradient ＝ 走之前先看地形的梯度下降**（步伐要除以代價）。
2. **RMPflow 的核心方程式 ＝ natural gradient ＋ 阻尼 ＋ 曲率修正。**

## 概念 4：GDS ——把「彈簧＋阻尼」升級成可以描述任何 RMP 的四零件

> 📖 **先看：論文式 (3)（第 8 頁，4.1 節）**。你在概念 2 第 6 階已經拆過它了，這節是把四個零件一個一個講清楚。

GDS（Geometric Dynamical System，幾何動力系統）是論文第 4 章整章的語言。名字嚇人，內容其實是高中物理的四個零件。

### 第 1 階：高中的彈簧－阻尼系統

一顆球接在彈簧上，整個泡在水裡。三樣東西決定它怎麼動：

| 零件 | 決定什麼 |
|---|---|
| **彈簧的位能** | 它「想去哪」——位能最低的地方（彈簧的自然長度處） |
| **水的黏滯（阻尼）** | 它多快停下來。沒有水的話球會永遠來回振盪 |
| **球的質量** | 同樣的力能推動多少。越重越推不動 |

放手之後，球會朝位能低的地方走，來回幾次，被水的阻力吃掉能量，最後停在最低點。**整個 GDS 就是這個系統的升級版。**

### 第 2 階：把「質量」升級成「方向性的質量」

一般物體的質量是**一個數字**：不管你從哪個方向推，它都一樣重。

GDS 的第一個升級：**每個方向可以不一樣重**，而且這個「重」還可以隨位置、隨速度改變。

這個東西你已經認識三次了，只是名字不同：

> **同一個 G，三種讀法：**
> - **發言權**（2018 那篇的說法）：這個方向我多有意見
> - **移動代價**（概念 1 的說法）：往這個方向走一步要付多少錢
> - **方向性的質量／慣性**（本節的說法）：這個方向多難推動
>
> 三者完全等價：**難推動 ＝ 走起來貴 ＝ 我很在意。**

（避障度量 `w(d)·ŝŝᵀ` 用這個讀法就是：「朝向障礙物那個方向重得像座山，側向輕得像羽毛」。所以合成時它在側向推不動別人，在朝障礙方向誰也推不動它。）

### 第 3 階：四個零件的正式名單

論文把一個 GDS 寫成四元組 `(M, G, B, Φ)`：

| 符號 | 讀法 | 是什麼 | 對應彈簧例子 |
|---|---|---|---|
| `Φ` | phi | **位能**：決定它想去哪（往位能低處走） | 彈簧位能 |
| `B` | — | **阻尼**：決定它多快停下來 | 水的黏滯 |
| `G` | — | **度量**：方向性的質量／代價／發言權 | 球的質量（升級成分方向） |
| `M` | — | **有效慣性** `M = G + Ξ_G` | 沒有對應——這是新東西 |

### 第 4 階：為什麼 M 不等於 G（多出來的 Ξ_G）

彈簧例子裡質量就是質量，沒有第二個。但這裡的「質量」`G` 是會變的（隨位置、隨速度）。

**一個會變的質量，在計算加速度時會多出修正項**——這正是概念 2 講的曲率項。所以真正要用來算加速度的不是 `G` 本身，而是 `M = G + Ξ_G`：**代價地圖，加上「代價地圖正在改變」帶來的那份修正**。

一句話：**`G` 是地圖，`M` 是「把地圖會變這件事也算進去之後，實際感受到的慣性」。**

### 第 5 階：GDS 家族的三層階梯（論文 4.1、4.5 節）

同一條式 (3)，`G` 的複雜度不同，就退化成不同的既有方法：

| `G` 的形式 | 退化成什麼 | 意思 |
|---|---|---|
| `G` = 常數 | **OSC（Operational Space Control）** | 各方向一樣重、到哪裡都一樣重。這是 1987 年 Khatib 的經典方法，也是論文的對照組 |
| `G = G(x)`（只跟位置有關） | **SMS（simple mechanical system）**，即古典力學的機械系統 | 此時 `ξ_G` **就是 Coriolis 力** `C(x,ẋ)ẋ` |
| `G = G(x, ẋ)`（還跟速度有關） | **本篇的新領土** | 傳統剛體力學做不到；能表達「朝障礙物走才在意」 |

看懂這張表，就看懂了論文 4.5 節在講什麼：**RMPflow 不是要取代 OSC，而是把 OSC 包成自己最簡單的特例。**

### 對應到 G1 專案

你 yaml 裡每個控制器其實都是一個 GDS，四個零件都在：

| 控制器 | `Φ`（想去哪） | `B`（阻尼） | `G`（在意哪些方向） |
|---|---|---|---|
| target attractor | 離器械越遠位能越高 | 防止衝過頭 | 三個方向都在意（近似 `w·I`） |
| 避障（body_cylinders） | 靠近障礙物位能暴增（barrier） | 逼近時額外阻尼 | `w(d)·ŝŝᵀ`，只在意朝向障礙的方向 |
| joint limit | 靠近極限位能暴增 | — | 只在意「朝極限移動」 |

### 檢驗自己是否懂了

1. `Φ`、`B`、`G` 各自決定行為的哪一面？用彈簧泡在水裡的例子講。
2. 為什麼 `M = G + Ξ_G` 而不是 `M = G`？
3. `G` 是常數時，RMPflow 退化成哪個經典方法？

## 概念 5：Lyapunov 穩定性——為什麼能證明「它一定會停下來」

> 📖 **本節無圖**。想要動畫版可以搜尋「Lyapunov stability intuition」或 Steve Brunton 的 Control Bootcamp 系列。

論文 4.3 節花了整節證明 RMPflow 是穩定的。這一節講清楚那個證明在說什麼。

### 第 1 階：碗裡的球（這次「碗」是對的比喻）

> ⚠️ 先講清楚一件事：概念 2 特別警告過**不要**用「碗」來想曲率項，因為碗會夾帶「滑向中心」的暗示。但**這一節的碗是正確的**——因為 Lyapunov 穩定性要講的，恰恰就是「東西會滑到最低點然後停下來」。同一個比喻，用在對的地方是對的，用在錯的地方會害人。看清楚它現在指的是哪件事。

一顆球在碗裡，碗底有摩擦力。不管你從哪裡放手、用多大力氣丟進去，結果都一樣：**滾一滾，最後停在碗底。**

為什麼你這麼確定？因為你知道兩件事：

1. 球的**總能量**（動能＋位能）不會憑空增加
2. 只要球還在動，摩擦力就一直在**消耗**能量

能量只減不增、而且只要在動就一定在減 → **它只能停下來，沒有別的結局。**

**這就是 Lyapunov 的全部思想。** 不必解出球的軌跡方程式，只要找到一個「只減不增」的量，就能斷定結局。

### 第 2 階：把「能量」寫成式子

高中物理的總能量：

```
總能量 =  ½ m v²   +   位能
         └─動能─┘
```

論文用的能量函數（4.3 節的 Lyapunov candidate）：

```
V(q, q̇) = ½ q̇ᵀ G(q, q̇) q̇  +  Φ(q)
          └────動能────┘     └位能┘
```

一模一樣的結構，只有一個地方換了：**質量 `m` 換成了度量 `G`**。

這裡可以看出概念 4 第 2 階那個「G 是方向性的質量」有多貼切——它真的被放在質量的位置上用。（`q̇ᵀ G q̇` 就是「把每個方向的速度，用該方向的『重量』加權後加起來」，`½mv²` 的分方向版。）

### 第 3 階：證明的核心一行

論文 Proposition 1 說：

```
V̇ = − q̇ᵀ B q̇
```

`V̇` 是能量的變化率。等號右邊有個負號，而 `q̇ᵀBq̇` 在阻尼 `B` 為正時一定 ≥ 0。所以：

> **V̇ ≤ 0：能量只減不增。而且只要還在動（`q̇ ≠ 0`），就一直在減。**

翻成白話：**只要機器人還在動，阻尼就一直在漏掉能量；不動了才停止漏。** 這正是碗裡的球那兩句話的數學版。

注意等號右邊**只有阻尼 `B`**——`G`、`Φ`、曲率項全部消失了。這是整個證明最漂亮的地方：那些幾何項不會憑空製造能量（物理上叫「不作功」），所以搗亂的只可能是阻尼。

### 第 4 階：結論（Corollary 2）

`G` 和 `B` 都是正定（各方向都真的有重量、都真的有阻尼）時，系統會收斂到：

```
{ ∇Φ(q) = 0  且  q̇ = 0 }
```

白話：**最後會停在「坡度為零」的地方，而且速度為零。** 就是球停在碗底。

（`∇Φ = 0` 的地方就是位能的平坦處——通常是目標點。這也是為什麼論文說要保證 `B ≻ 0`：只要複製一份 C-space 節點、掛一個小小的正定阻尼上去就行。）

### 第 5 階：Theorem 2 在補什麼洞

上面的推論有個前提：能量函數 `V` 得是個「像樣的」能量。當 `G` 只跟位置有關時這沒問題。但**本篇的 `G` 還跟速度有關**——這是新東西，前人沒證過，也真的可能出事。

想像一個壞掉的設計：**你越是逃離障礙物，地變得越黏**。這種代價地圖會讓系統在某些走法下「能量憑空增加」，於是永遠停不下來。

Theorem 2 給的就是排除這種情況的充分條件。1D 版本白話講是：

> 對每個一維的距離空間，代價 `g(x, ẋ)` 必須滿足：
> - **朝障礙物移動時（`ẋ > 0` 定義為逼近）：代價不遞減**
> - **遠離障礙物時：代價不遞增**

也就是——**代價可以「靠近時變貴」，但不可以「逃跑時變貴」。** 論文 3.6 節設計的避障策略（`u(ẋ)` 只在逼近時增大、遠離時設成常數）正好滿足這個條件，所以它是穩定的。

### 檢驗自己是否懂了

1. 為什麼不必解出軌跡，就能斷定球會停在碗底？
2. `V = ½q̇ᵀGq̇ + Φ` 和高中的 `½mv² + 位能` 差在哪裡？
3. `V̇ = −q̇ᵀBq̇` 這一行為什麼只剩下阻尼？
4. 什麼樣的度量設計會害系統停不下來？

## 概念 6：座標無關性——為什麼同一組控制器可以換一台機器人用

> 📖 **先看：論文 Fig. 5（第 14 頁）**。右邊兩張是 ABB YuMi 和 Rethink Baxter，兩台構造完全不同的雙臂機器人，跑的是同一套 RMP 設計。本節就是在解釋這件事憑什麼成立。

### 第 1 階：公制與英制

一段距離，可以說「100 公尺」也可以說「328 英尺」。數字完全不同，但有些事情不會變：

- 哪一段比較長，不會因為換單位而改變
- 兩個人賽跑誰先到，不會因為你用公制紀錄而改變

**數字是「座標」，會變；事實是「幾何」，不會變。**

### 第 2 階：機器人版本

同一隻手臂，可以用不同方式描述：關節角度、末端座標、甚至別人設計的另一套參數。更進一步——**YuMi 和 Baxter 雖然是兩台不同的機器人，但「末端要移動到桌上某點、同時避開障礙物」這件事在兩台上是同一個任務**。

所以問題變成：

> 我在任務空間（末端位置、離障礙物的距離）設計好的行為，換一台關節構造完全不同的機器人，還會是同一個行為嗎？

如果答案是「不一定」，那每換一台機器人就要重調全部參數。

### 第 3 階：pullback 是幾何操作（論文 Theorem 3、4）

論文 4.4 節證明的就是：**會，是同一個行為。**

理由是 `pullback` 搬東西時，**策略和它的量尺（度量）是綁在一起搬的**——你在 2018 學的 `JᵀAJ` 就是這件事，概念 3 的 natural gradient 也遵守同一條規則。這種「連量尺一起搬」的搬法，搬出來的是**幾何物件**，不依賴你用哪組座標描述。

論文用的正式工具叫 **affine connection（仿射聯絡）**。你不需要會算它，只要知道它是什麼角色：

> **affine connection ＝ 在彎曲空間裡，「怎麼把不同位置的向量拿來比較」的規則。**

平坦空間裡兩個箭頭要比較，平移過去比就好。彎曲空間裡沒這麼簡單（地球上從台北往北的箭頭，搬到紐約還算「往北」嗎？），需要一套規則。論文證明：**RMPflow 的 pullback，就是這套規則在幾何上的正確版本。**

### 第 4 階：實務意義

這就是 2018 那篇實驗結論「同一組控制器換機器人幾乎免調參」的理論根據——2018 是實驗觀察，本篇把它證成定理。

對你 G1 專案的意義：一組寫好的子任務 RMP（末端 attractor、避障、關節極限），理論上換到左手臂、換到別台機器人、甚至換一套 URDF 參數，**任務空間的行為會保持一致**。要重寫的只有 task map（`ψ` 和它的 Jacobian），那部分本來就是機器人特有的。

2. 為什麼 pullback 能保證換機器人行為不變？關鍵在它搬了什麼？

## 概念 7：兩趟遍歷——forward pass 與 backward pass（論文 3.3–3.5 節）

> 📖 **先看：論文 Fig. 1（第 4 頁）**。三種樹的形狀：(a) 只有一個任務、(b) 多個任務並列、(c) 機器人運動鏈的樹。你的 G1 屬於 (c)。

### 第 1 階：這是計算圖，不是迭代迴圈

論文標題就寫了「computational graph（計算圖）」。最好的類比是你訓練 YOLO 時的 forward／backward pass：

| | 神經網路 | RMPflow |
|---|---|---|
| forward pass | 輸入影像 → 逐層算出 activation | 關節狀態 `(q, q̇)` → 逐層算出各任務點的位置與速度 |
| backward pass | 從 loss 用 `Jᵀ` 把梯度傳回各層 | 從各子任務用 `Jᵀ` 把「力＋度量」傳回關節 |

**每個控制週期做一次（1 kHz 就是每秒 1000 次）。一來一回走完就結束——沒有檢查、沒有退回、沒有重算。**

> ⚠️ 常見誤解：以為第二趟是「檢查 OK 不 OK，不 OK 再拉回去調整」。**沒有這回事。** 如果真要迭代求解，根本跑不到 1 kHz——那是 cuRobo 那類最佳化方法在做的事。

### 第 2 階：為什麼一定要兩趟、而且順序不能反

兩種資訊的流向天生相反：

- 「**我現在在哪**」只能從關節往外推：手掌在哪、手肘離柱子多遠，都是關節角決定的 → 必然 root → leaf
- 「**我該怎麼動**」只能從任務收回來：是避障和 attractor 在決定關節怎麼轉 → 必然 leaf → root

而且**先後不能顛倒**：避障策略要算出「我要多大的斥力」之前，必須先知道「我離柱子 5 公分、正以 0.3 m/s 逼近」——那個數字是第一趟才算得出來的。

### 第 3 階：跑一個 G1 的週期

```
【第一趟 pushforward：發狀況】（論文 3.4 節第 1 點）
根節點  q = 7 個關節角, q̇ = 7 個關節角速度
  ├→ 手掌節點      x = (0.42, 0.10, 0.85) m,  ẋ = J q̇ = (0.05, 0, −0.20) m/s
  ├→ 手肘避障節點  d = 0.05 m,  ḋ = −0.30 m/s   ← 負號＝正在逼近
  └→ 關節極限節點  距上限還有 0.2 rad, 正以 0.5 rad/s 往上限跑

【各葉節點出意見】（現在才有辦法算，因為要先知道自己在哪）
  手掌 attractor：我要往器械加速 a = (1.2, −0.3, 0.4)，度量 M = 2·I
  手肘避障：      我要沿遠離柱子方向加速 8 m/s²，度量 m = 50·ŝŝᵀ（一根針）
  關節極限：      第 3 軸別再往上衝，度量在該軸很大

【第二趟 pullback：收意見】（論文式 1）
  每個意見用 Jᵀ 換算回關節座標 → 全部加總 → 根節點 resolve 一次
  → 得到 7 個關節加速度 → 送出去 → 這個週期結束
```

### 第 4 階：三個運算子的正式名字（論文 3.4 節）

| 運算子 | 方向 | 傳什麼 | 公式 |
|---|---|---|---|
| `pushforward` | 根 → 葉 | **狀態**（位置、速度） | `y = ψ(x)`、`ẏ = J ẋ` |
| `pullback` | 葉 → 根 | **RMP**（力、度量） | `f = Σ Jᵢᵀ(fᵢ − Mᵢ J̇ᵢẋ)`、`M = Σ JᵢᵀMᵢJᵢ` |
| `resolve` | 只在根節點 | 把力換算成加速度 | `a = M† f` |

`pullback` 的意義（論文式 2）：等價於一個**加權最小平方**——所有控制器同時發言、按各自的度量加權，一次求出折衷。**不是誰說了算，也不是輪流修正。**

### 第 5 階：為什麼複雜度是 O(K)（論文 3.5 節）

利用樹的結構，共用的計算路徑只算一次。K 個子任務的最壞情況是 `O(K)`，而不聰明的做法是 `O(K log K)`。除了根節點那一次求逆之外，全部都是矩陣乘法——這是它能跑在 1 kHz 的原因。

## 概念 8：canonical form 與 natural form（論文 3.2、3.4 節）

### 第 1 階：同一件事的兩種說法

國中的 `F = ma` 就夠了。一個 RMP 有兩種寫法：

| 形式 | 內容 | 白話 |
|---|---|---|
| **canonical form** `(a, M)` | 想要的**加速度** ＋ 度量 | 「我要時速 100」 |
| **natural form** `[f, M]` | 想要的**力** ＋ 度量，`f = M a` | 「我踩這麼深的油門」 |

（注意本篇改了 2018 的命名：2018 的 `f` 是加速度策略、`A` 是度量；本篇 `a` 才是加速度，`f` 改指力，度量叫 `M`。看兩篇論文時要換腦袋。）

### 第 2 階：為什麼回傳時非用「力」不可——力能相加，加速度不能

高中物理：甲出 3 N、乙出 5 N 推同一個箱子，合力 8 N，直接加。

但如果甲說「我要 3 m/s²」、乙說「我要 5 m/s²」，**不能**加成 8 m/s²——加速度取決於箱子多重。正確做法是各自換回力、加總，最後再除以總質量。

`pullback` 做的就是這件事：

```
力    ：f = Σ Jᵢᵀ (fᵢ − Mᵢ J̇ᵢ ẋ)     ← 全部加起來
度量  ：M = Σ Jᵢᵀ Mᵢ Jᵢ              ← 全部加起來
根節點：a = M† f                     ← 最後「除以總質量」一次
```

### 第 3 階：數值上的理由（論文 3.5 節）

你的避障度量 `ŝŝᵀ` 是「一根針」——只有一個方向有值，其他方向全是零。這種矩陣**不可逆**（等於要除以 0）。

如果每一層都用加速度形式傳，每層都得做一次 `M†`，一路踩地雷。改用力的形式一路加總，到根節點時 `M` 已經是所有控制器的貢獻疊起來（通常滿秩），**只需要求逆一次**。

論文原話：這個設計讓 RMPflow「numerically stable」。

## 概念 9：`J̇ẋ` 修正項（論文式 1、Fig. 2）

> 📖 **先看：論文 Fig. 2（第 12 頁）四格**。(a) 是設計的目標行為、(b) 是正確算了 `J̇q̇`、(c) 是忽略它、(d) 是忽略它但加上非線性阻尼。重點在 (c)(d) 和 (a) 長得不一樣。

### 第 1 階：加速度的換算會多一項

速度的換算：`ẋ = J q̇`。兩邊對時間微分（高中微積分的乘法律）：

```
ẍ = J̇ q̇ + J q̈
```

多出來的 `J̇q̇` 就是本節的主角。**2018 那篇的 pullback 忽略了它，本篇把它加回去。**

### 第 2 階：`J̇ ≠ 0` 代表什麼

`J` 是 `q` 的函數，手臂一動 `J` 就跟著改寫：**同樣的關節角速度，在不同姿勢下對末端造成的效果不一樣**（手臂伸直時肩關節轉 1 rad/s，末端跑得飛快；收起來時幾乎不動）。

後果：**就算關節速度完全不變（`q̈ = 0`），末端仍然在加速。** 等速旋轉的手臂就是這樣——關節加速度為零，末端卻有向心加速度，那份就是 `J̇q̇`。

### 第 3 階：旋轉木馬

你站在**旋轉木馬**上想朝中心走，心裡想「我要以 1 m/s² 前進」。但平台在轉，就算你腳不動，你也已經被甩著在加速。要真的達成你想要的加速度，**必須先把平台塞給你的那一份扣掉**。

```
f = Σ Jᵢᵀ ( fᵢ − Mᵢ J̇ᵢ ẋ )
             ↑         ↑
       我要的力    先扣掉「什麼都不做也會發生」的那份
```

葉節點說「我要 `aᵢ`」，實際會得到的是 `Jq̈ + J̇q̇`，所以關節要提供的是 `Jq̈ = aᵢ − J̇q̇`。

### 第 4 階：Fig. 2 的教訓——穩定 ≠ 正確

論文的 1D 實驗結論：

| | 結果 |
|---|---|
| (b) 正確包含 `J̇q̇` | 行為符合設計 |
| (c) 忽略 | 行為不一致，而且不穩定 |
| (d) 忽略但加非線性阻尼 | **穩定救回來了，但行為依然是錯的** |

**記住 (d)**：機器人沒有發散、看起來乖乖的，不代表它在做你設計的事。

## 概念 10：速度相關度量（論文 3.6 節）

### 吹風機的方向感

避障度量寫成 `g(x, ẋ) = w(x) · u(ẋ)`：

| 因子 | 看什麼 | 設計 |
|---|---|---|
| `w(x)` | **離障礙多近**（位置） | 越近越大。2018 就有 |
| `u(ẋ)` | **正在靠近還是遠離**（速度） | 逼近時（`ẋ < 0`）變大；遠離時（`ẋ ≥ 0`）設成**常數** |

效果：機器人**背對障礙物時，這個 RMP 在 pullback 裡等於被關掉**。

論文特別點名這件事「傳統剛體力學原理無法捕捉」——古典力學的慣性矩陣只跟位形有關，不會隨你往哪走而改變。這是本篇相對 2018 最大的理論領土（也是 Theorem 2 要處理的難點，見概念 5 第 5 階）。

### 對應到 G1 專案

G1 拿著盒子沿走廊走，右邊有牆：

- **只看位置的度量**：整條走廊都在「怕牆」，動作變黏、繞遠路
- **速度相關度量**：只有真的往牆偏過去時才作用，平行走過去時牆等於不存在
