# TTS 音檔：全大寫被逐字母唸、希臘字母唸不出來

- **日期**：2026-08-16
- **嘗試的方法**：用 macOS `say -v Meijia` 把 RMP 論文講稿轉成音檔，直接拿書面用的 Markdown 講稿去轉，沒有做任何前處理。
- **為何失敗**：
  1. **全大寫的詞會被逐字母唸出**。`NVIDIA` 唸成「N、V、I、D、I、A」而不是「Nvidia」。使用者聽了才發現，agent 無法試聽，這類問題不會在產生階段暴露。
  2. **希臘字母唸不出來**：講稿裡的 α、β、φ 中文語音無法正確發音。
  3. 另外 `say -f 檔案` 讀 UTF-8 會報 `Input text is not UTF-8 encoded`（加 BOM 也無效），要改用參數傳入文字。
- **替代方案**：產生音檔前先做「朗讀正規化」，且只作用在朗讀版，書面講稿維持正確寫法：
  - 應唸成一個字的全大寫詞改首字大寫（`NVIDIA` → `Nvidia`）；本來就該逐字母唸的縮寫（`RMP`、`MPC`、`DMP`、`PID`）維持全大寫。
  - 希臘字母改英文拼法（α → alpha、β → beta、φ → phi …）。
  - 產生前先掃描文字、列出所有全大寫詞與希臘字母，逐一確認唸法。
  - 規則已寫入 `skills/research/slide-maker/SKILL.md`。
- **通用教訓**：**agent 產出「自己無法驗收的媒材」（音檔、影片）時，要主動列出可能的失真點請使用者確認**，不能產完就當作完成。視覺產出可以自己轉圖檢查，聽覺產出目前只能靠使用者回饋。
