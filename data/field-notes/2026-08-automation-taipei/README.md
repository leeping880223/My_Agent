#### 1. 工研院 資通所｜「照片級擬真 3D 模型建構與展示技術」VenReal 3D ★★★ 對論文最有用

講者：吳欣怡 技術經理（現場）

- **技術**：3D Gaussian Splatting（3DGS）。技術演進 MVS/SfM → NeRF(2020–2022) → **3DGS(2023~)**；流程為 SfM 初始點雲 → 神經網路優化 3D Gaussians → 輸出 `.ply`
- **工具鏈**：iOS APP／Web 拍照 → 雲端 3DGS 建模 → 儲存 → Web Viewer 展示，模型可下載
- **成本對比（他們的數字）**：傳統 3D 建模約 **3 萬元／4 人天**；3DGS **0.5–1 小時／次**，宣稱擬真還原度 95% 以上
- **拍攝要領**：繞物體上／中／下各一圈；**反光或結構複雜處要多拍**；**透明或高反光物體拍攝難度較高**
- **本人已實測（現場）**：當場用 APP 掃了展台上的公仔——APP 流程為 Detecting Plane and Object → 自動生成 37 個建議拍攝點 → Auto Capturing 拍到 93 張 → Finish。**整套流程本人已經跑過一次**
- **限時活動（現場 DM）**：Q1024 攤位，加 LINE 官方帳號輸入通關密語 **「AUTO2026」**，**2026/09/05 截止**；成功建模回傳可獲延長免費試用 1 個月 ＋ 2 次模型處理服務；展期間可預約現場為展品拍照建模
- **對論文的意義**：手術器械的 USD/Mesh 資產目前是自己準備的。3DGS 提供「拍照 → 3D 資產」的低成本路徑，且**工研院正是本論文的合作單位**。⚠️ 但要注意他們自己講的限制：**高反光金屬件（手術器械正是）拍攝難度高**——這點必須實測才算數

## 跨公司的三個觀察（分享報告可以用這個當骨幹）

1. **人形機器人在台灣已經形成完整供應鏈，而不是單點嘗試**
   關節／傳動（上銀、富田）→ 控制器與邊緣運算（研華、磐儀）→ 整機與代理（達明、台智寶、至盛/Unitree）→ 應用與 SI（Solomon、新代）。同一個展場走一圈就能把上下游看完。
2. **「模擬先行」成為公開的方法論**
   達明用 Isaac Sim ＋ GR00T 合成資料、研華畫出六階段數位孿生藍圖、新代用數位孿生做部署前規劃。**共同邏輯：真實資料太貴，先在模擬裡練。**
3. **LLM／VLA 進到機器人，但分工很清楚**
   FANUC 是 LLM 產生高階 API 呼叫；Solomon 是語言指令驅動人形完成移動＋抓取；研華直接把「傳統 code-based vs VLA」並排比較。**現階段是「語言當介面、傳統控制當底層」，不是端到端取代。**
   對照組：新代明講「真正多用途人形還很遠」——展場上有樂觀也有保留，報告時兩邊都講會更有說服力。
