# 外部見聞紀錄（展覽／研討會／參訪）

放**外部活動**的第一手見聞：展覽、發表會、研討會、公司參訪。與 `paper-library/`（論文）、`dev-log/`（自己踩的坑）互補——這裡記的是「別人在做什麼」。

## 什麼東西該放這裡

- 看到的公司／產品／demo，以及當下的判斷與疑問
- 現場素材（照片、錄音、DM）與從中整理出的重點
- 由這次見聞衍生的產出（報告、分享簡報）

## 命名規則

一個活動一個資料夾：`<年份>-<月份>-<活動簡稱>`，例：`2026-08-automation-taipei`。
資料夾內固定有 `README.md`（活動總覽＋逐家紀錄）與 `media/`（照片、錄音等原始素材）。

## 見聞會流向哪裡（記完之後要分流）

| 內容性質 | 流向 |
|---|---|
| 新技術／現成方案，可能影響論文技術路線 | `dev-log/`、`goals.md`＋`plan-changelog.md` |
| 產業／職缺／公司線索 | `career-plan/job-targets.md`、`career-plan/current-plan.md` |
| 對某類工作的感受（喜歡／不喜歡） | `profile/task-feelings.md` |
| 面試可用的故事素材 | 由 `career/story-builder` 讀取本資料夾 |
